## 研究定位

**暫定題目**為 Evidence-Grounded Housing Transaction Comparison in Taiwan Using a Bounded ReAct Agent。研究目標是讓住宅成交樣本比較可追溯至資料版本、篩選、價格口徑與相關規則。具體場景暫以臺中住宅為候選，先做描述性比較。

方法是由 typed query、經授權唯讀工具與確定性統計提供結構化數值，再以 bounded ReAct 調度、版本化 RAG 補充文件，經 Evidence Gate 檢查來源、單位、時效及適用條件。可用證據不足時回傳條件式部分答案或停止。MR-004 是主要技術提案，涉及精細 GIS、估價及模型解釋的功能有條件納入。參考 MR-004 §§3–13、SUP-001 §§4–5 和 SUP-002 投影片 17–18、31–32。

主要假設是相同資料、工具及證據政策下，adaptive orchestration 可能改善多步或異常情境的有據任務完成率，同時造成額外工具成本或延遲。這是待驗證的比較問題。現有材料未顯示 Agent 實作、完成的對照實驗、模型訓練或使用者研究。
