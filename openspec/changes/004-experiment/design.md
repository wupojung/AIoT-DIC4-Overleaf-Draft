# 004-experiment — Design

## Context

參見 [proposal.md](proposal.md) 與[證據報告](../../../research/academic-plan/INSPECTION.md)。可獨立撰寫評估規格；執行前須確認 003 的共同條件、研究母體／日期語義及實驗環境與資料權利。輸出交給 005／000。

## Goals / Non-Goals

- 交付。英文 Experiment 計畫、資料字典與篩選紀錄、成對測試與評分規約，以及核准後具來源的實驗結果和威脅分析。
- 本次規格審閱只涵蓋寫作方法與可驗收產物。正文、原型、實驗執行及投稿依核准範圍另行安排。

## Decisions

- 採資料盤點與 Agent 對照兩層驗證。將資料版本、條件、輸出列數與欄位判定綁定至官方資源。
- 成對對照固定其他條件，記錄共同資源上限、案例類別、獨立評分、計分單位與結果不確定性。
- 來源。MR-001 Q–V、MR-002 §6、SUP-001 §5、SUP-003 §§3／11–14、E-01／E-02、EXT-002／EXT-004，以及 003 的設計契約。 MR-004 §§3、11–14 是優先技術來源。MR-003 §§2.5、3.5、4.2 提供指標和資料字典的待查項目。
