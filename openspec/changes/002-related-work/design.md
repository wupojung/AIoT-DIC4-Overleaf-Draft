# 002-related-work — Design

## Context

參見 [proposal.md](proposal.md) 與[證據報告](../../../research/academic-plan/INSPECTION.md)。006 可平行審核 metadata；研究缺口交給 001，方法取捨交給 003／004。

## Goals / Non-Goals

- 交付。英文 Related Work 和可追溯比較表，欄位含資料／場域、方法、任務、評估、限制及本研究對應。
- 本次規格審閱只涵蓋寫作方法與可驗收產物。正文、原型、實驗執行及投稿依核准範圍另行安排。

## Decisions

- 文獻分兩條主軸並以比較矩陣統一閱讀維度。將研究目標、母體、地域及測試條件保留在每筆比較中。
- 以原文頁節支持每個限制或方法判斷；MR-003 提及的 23 篇與課堂配比僅為盤點線索。
- 來源。MR-001 M–O、MR-002 §3、SUP-001 §§2–3、EXT-003 至 EXT-008，以及後續 006 的一手來源查核表。 MR-003 §§2.3、3.2 的候選文獻與比較表建議。其列舉與評價只是待查線索。

## Risks / Trade-offs

- 取得不到可支持的全文段落時，保留 metadata 狀態並縮小或延後該主張。
- 引文和數值皆依 [spec.md](specs/literature-comparison/spec.md) 及全稿規格驗收，審查紀錄保留原文件頁節、來源 ID 與證據狀態。
