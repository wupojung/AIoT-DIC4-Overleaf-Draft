# 006-reference — Proposal

## Why

建立可查核的一手文獻與資料來源記錄，並確保 IEEE 依首次出現排序的數字引用一致。

## What Changes

- 規劃本節的英文稿及審查材料。書目 metadata 與 DOI／網址查核紀錄、主張對應表、去重紀錄，以及核准後的 IEEE bibliography 與編譯檢查。
- 使用指定來源並以可追溯的證據狀態驗收。參考盤點、MR-001／002 來源角色、SUP-001 References、既有 DR-001 引用鍵、EXT-001 至 EXT-010，以及 001–005 的引用主張。
  - MR-003 §§2.3、3.2 的文獻名稱僅作搜尋線索；MR-004 所指官方資料需查原站與適用條件。

## Capabilities

### New Capabilities

- `citation-traceability` — 建立可查核的一手文獻與資料來源記錄，並確保 IEEE 依首次出現排序的數字引用一致。

### Modified Capabilities

## Impact

- 寫作依賴。可在其他章節之前建立查核規則並平行整理文獻；最後隨正文順序關閉引用、重複、未引用及懸空檢查。
- 依 [全稿寫作規格](../../../research/academic-plan/EXECUTION.md) 與 [來源盤點](../../../papers/REFERENCE-INVENTORY.md) 審查。獲核准後才進入正文實作。
