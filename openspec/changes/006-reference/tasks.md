## 1. 來源與交付

- [ ] 1.1 核對作者、題名、年份、出版處與 DOI／官方網址；分欄紀錄 metadata、全文與主張查核。交付帶狀態及原文位置的來源清單。
- [ ] 1.2 依 DOI 正規化，無 DOI 時比對題名、首作者、年份與版本，紀錄合併決策。確認同一來源沒有重複鍵。
- [ ] 1.3 為正文主張記錄精確頁節、資料版本或摘錄位置及審查狀態。抽查所有量化與主要方法主張均有支持記錄。
- [ ] 1.4 組稿後編譯檢查 IEEE 數字排序、懸空引用與未使用條目，交叉驗收 000。核對編譯紀錄沒有懸空引用且首次出現順序正確。
